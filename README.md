# Rishit Gupta — Professional E-Portfolio

A single-page professional portfolio built with React, Vite and Bootstrap.

## Professional positioning

**Operations | Supply Chain | Analytics | Technology**

The portfolio highlights:

- Operations and logistics
- Supply chain
- Excel analytics
- Power BI dashboards
- SQL and databases
- Six Sigma / TQM
- Process improvement
- AI-assisted operations
- Technology experience
- International immersion

## Technology

- React
- Vite
- Bootstrap 5
- Bootstrap Icons
- Custom CSS
- GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
